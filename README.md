# FitStart AI — фінальна версія

**Дата: 3 листопада 2026**

Ця папка містить повний робочий проєкт FitStart AI: вихідний код, конфігурацію, залежності та готову продакшн-збірку.

## Як запустити

Потрібен встановлений Node.js (версія 18+).

```bash
npm run dev
```

Після запуску відкрий адресу, яку покаже Vite (зазвичай http://localhost:5173).

## Готова збірка

Папка `dist/` уже містить продакшн-версію. Переглянути її локально можна так:

```bash
npm run preview
```

## Перевірки якості

```bash
npm run typecheck
npm run lint
npm run build
```

Усі три команди проходять успішно.

## Що є в проєкті

- Головна сторінка з персональним привітанням і прогресом дня
- Рецепти з наявних продуктів
- Домашні тренування
- Чек-лист здорових звичок
- Трекер води
- FitBuddy AI — чат-помічник
- Обране
- AI-профіль користувача: стать, зріст, вага, зовнішність
- Параметричний SVG-аватар, що змінюється за параметрами профілю
- Адаптивний дизайн: сайдбар на десктопі, нижня навігація на мобільному
- Error Boundary для захисту від білого екрана

## Де зберігаються дані

Дані користувача (профіль, звички, вода, обране, налаштування AI) зберігаються в `localStorage` браузера, а не в цій папці.

API-ключ OpenRouter вводиться в застосунку через «Налаштування AI» і зберігається лише локально в браузері.

## Структура

```
src/            вихідний код застосунку
public/         статичні файли
dist/           готова продакшн-збірка
node_modules/   встановлені залежності
```

## Примітка

AI-функції працюють у двох режимах:

- **Демо-режим** — без API-ключа, з готовими прикладами.
- **AI-режим** — після додавання ключа OpenRouter у налаштуваннях.
