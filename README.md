# FitStart AI

**🌐 Опублікований сайт: https://natalia9601.github.io/FitStart_AI/**

## Про застосунок

FitStart AI — це вебзастосунок для здорового способу життя без стресу та провини. Можна вести щоденні звички, трекер води та кроків, рахувати калорії й КБЖУ, шукати прості рецепти з продуктів під рукою, тренуватись вдома без обладнання та спілкуватися з дружнім AI-помічником FitBuddy. Усе з персоналізованим AI-образом, який будується за твоїми параметрами (стать, зріст, вага).

## Головні функції

- **🏠 Дашборд** — «Баланс дня», кільцеві прогрес-індикатори води, звичок, кроків і калорій, тижнева активність, серія днів поспіль.
- **🥗 Рецепти (FitStart Express)** — AI-генерація простих рецептів з продуктів, що вже є вдома; пошук у результатах, копіювання інгредієнтів.
- **🍎 Калорії та КБЖУ** — прийоми їжі (сніданок/обід/вечеря/перекус), donut-діаграма БЖУ, графік за 7 днів, підказки, рекомендована норма за формулою Mifflin–St Jeor.
- **💪 Тренування** — короткі розминки без обладнання, таймер, статистика за тиждень, історія тренувань і стрік.
- **✅ Звички** — м'який щоденний чек-лист, серія днів поспіль (streak), міні-графік за 7 днів.
- **💧 Вода** — добова норма за вагою (35 мл/кг), додавання по склянках, історія за 30 днів.
- **👣 Крокомір** — ручне та автоматичне (датчик руху) відстеження кроків, ціль на день, історія.
- **🤖 FitBuddy AI** — дружній AI-чат без осуду (OpenRouter), історія чату зберігається.
- **❤️ Обране** — збережені рецепти з пошуком, сортуванням і копіюванням інгредієнтів.
- **👤 Профіль і AI-образ** — параметричне зображення за зростом/вагою/IMT, або власне завантажене фото.
- **⚙️ Налаштування AI** — OpenRouter API-ключ, вибір моделі, експорт/імпорт даних (JSON + CSV-статистика).
- **📱 PWA** — застосунок можна встановити на телефон як додаток, є базовий офлайн-режим.

Усі дані зберігаються локально у браузері (localStorage).

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрийте http://localhost:5173/FitStart_AI/

## Збірка (production)

```bash
npm run build
```

Готовий bundle потрапляє у `dist/`. Для публікації на GitHub Pages workflow у `.github/workflows/deploy.yml` збирає проєкт і публікує його автоматично при push у `main`.

## Тести та перевірки

```bash
npm run typecheck   # перевірка типів
npm run lint        # ESLint
npm test            # юніт-тести (Vitest)
```

## Технології

React 18 + TypeScript + Vite, Tailwind CSS, Lucide-іконки, OpenRouter AI, Vitest.
